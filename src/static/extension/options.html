Press the leader key to open the which-key overlay (a paginated list of every Lazyfox binding plus native Firefox shortcuts); Tab / Shift+Tab flip pages, arrows select, or just press a binding's key. Changes apply immediately.

General

Leader key, link hints, and the core key behaviour.

Quick-launch apps

Web apps shown as tiles on the command-center home grid. Toggle each on or off; edit the name / URL or add your own. The favicon is pulled live from each site.

Sessions

tmux-style session manager: ;p save & switch named sets, ;' + 1-9 jump to a marker, ;| split, ;{/;} swap panes, ;\ close the split view.

Firefox chrome integration

Handled by chrome/userChrome.uc.js (installed by the Lazyfox installer). These hotkeys open Firefox's built-in pages and work even on about: / error pages where the extension can't run. Changes apply live — no restart needed.

Components & versions

Each Lazyfox piece versions independently: the extension, the Go wasm core, the native messaging host, and the chrome helper installed by the installer.
