Uninstall

To remove Lazyfox and return Firefox to normal, run the same installer and choose Remove Lazyfox (or run it with the uninstall argument). It removes only files Lazyfox added — your bookmarks, history, passwords, cookies and other add-ons stay exactly as they are.
