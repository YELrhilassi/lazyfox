Complete the installation

The Lazyfox add-on is installed and works on web pages (; leader, link hints, find, sessions…). The toolbar-free UI — the hidden tab strip and URL bar, the status bar, and the chrome-level ; keys on about: pages — is applied by a small standalone installer, because Firefox does not let an add-on write files itself. This page gets you that installer and walks you through it.

1 · Download the installer

One native, self-contained executable for your OS — no shell, no PowerShell, no toolchain. It writes only Lazyfox's own files into your profile (each with a .lazyfox.bak-* backup) and asks for admin rights once to drop the autoconfig loader into the Firefox install folder.

Download lazyfox-install

2 · Run it

    3 · Verify & restart

    Fully quit and restart Firefox (the changes apply at startup). Then come back here and press Verify — the status card above should flip to green.

    What gets installed

    Profile → chrome/userChrome.css · userChrome.uc.js · frame.js · corebootstrap.js · user.js (pref merge, yours are kept)
    Firefox install dir → config.js · defaults/pref/config-prefs.js (one-time admin)

    Your bookmarks, history, passwords and other add-ons are never touched. Everything is reversible by running the installer's uninstall action (the same executable, run with --mode uninstall).
